# Complex Number Calculator  
Барышев Вадим
## Описание  
Простой калькулятор для работы с комплексными числами. Реализованы базовые арифметические операции и логирование вычислений.  

## Структура проекта  

model/ Класс ComplexNumber (представление комплексного числа)  
operations/ Операции: сложение, умножение, деление  
service/ Основная логика калькулятора  
logger/ Логирование операций  
factory/ Фабрика операций  
controller/ Контроллер  
view/ ConsoleView  (взаимодействие с пользователем)
Main.java (точка входа в программу)
